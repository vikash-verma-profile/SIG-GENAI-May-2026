# Lab 5: React KPI Dashboard with v0.dev

**Domain:** Retail Supply Chain

## Objective

Generate a **React** monitoring UI with **[v0.dev](https://v0.dev)** (AI UI generation), then optionally deploy it.

## What you need

- v0.dev account (as required)  
- Node.js (for local run after export, if you download code)  
- Optional: [Vercel](https://vercel.com/) account for deployment  

## Steps

### 1. Open v0.dev

Go to [v0.dev](https://v0.dev/) and sign in.

### 2. Enter a prompt

Example:

> Create a React dashboard for supply chain monitoring with KPI cards, alert widgets, pipeline charts, and a responsive layout.

### 3. Generate the UI

Review:

- Tailwind-style layout (typical for v0 output)  
- Component structure  
- Charts or placeholders  

### 4. Export React code

Download or copy the generated React code into a local project if you need to run it outside v0.

### 5. Deploy on Vercel (optional)

Connect the repo or deploy per Vercel’s workflow so you have a public URL.

## Deliverables

- React dashboard (screenshots + repo or deployment URL)  
- Optional: Vercel deployment link  
- GitHub repository if you exported and versioned the code  

## Learning outcomes

- AI-generated React UIs  
- Tailwind-oriented dashboards  
- Frontend prototyping speed  

## Tips

- After the first generation, refine with prompts like “make KPI cards equal height on mobile.”  
- If deployment fails, fix build errors locally first, then push again.
