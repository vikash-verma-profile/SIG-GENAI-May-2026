# Lab 4: Replit Agent Pipeline Monitor

**Domain:** Telecom Monitoring

## Objective

Build a **pipeline monitoring** experience using **Replit Agent** with Python and Streamlit (or the stack Replit suggests).

## What you need

- [Replit](https://replit.com/) account  
- Replit Agent (per Replit’s current offering)  
- Basic familiarity with running apps in Replit  

## Steps

### 1. Open Replit

Sign in and open **Replit Agent** (or create a new AI-assisted Repl per current UI).

### 2. Create a new AI app

Choose a template aligned with the lab, for example:

- Python  
- Streamlit (if available in the agent flow)  

### 3. Enter a prompt

Example:

> Generate a telecom pipeline monitoring dashboard with: pipeline status, alert counts, failure history, and search.

### 4. Run the application

Use Replit’s **Run** / built-in hosting to start the app.

### 5. Validate the dashboard

Check that you have:

- Filters  
- Charts or visual summaries  
- Clear status indicators  

Fix gaps by prompting the agent again with specific requests.

## Deliverables

- Live Replit app (shareable URL)  
- Optional: export to GitHub if Replit supports it for your project  

## Learning outcomes

- AI-assisted development in a cloud IDE  
- Replit Agent workflow from prompt to runnable app  

## Tips

- If the first generation is shallow, ask for “add date range filter” or “add a table of last 10 failures” in separate prompts.  
- Document the share URL in your submission.
