# Lab 3: Lovable.dev Rapid Data App

**Domain:** Healthcare Analytics

## Objective

Create a **healthcare analytics dashboard** using **[Lovable.dev](https://lovable.dev/)** (AI-assisted app generation).

## What you need

- Web browser  
- Lovable.dev account (sign up as required by the platform)  

This folder includes **`sample_healthcare_etl.json`** and an optional local Streamlit preview (**`local_preview.py`**) if you want to explore the sample data offline: `pip install -r requirements.txt` then `streamlit run local_preview.py`.

## Steps

### 1. Open Lovable.dev

Go to [Lovable.dev](https://lovable.dev/) and sign in.

### 2. Enter a prompt

Example prompt (adapt as needed):

> Create a healthcare analytics dashboard with: patient ETL status, failed pipeline alerts, KPI cards, and search filters.

### 3. Generate the app

Observe what the tool produces:

- UI layout  
- Any backend or data wiring  
- Charts or summaries  

### 4. Customize the dashboard

Add at least a few of:

- Hospital or team branding (name, colors)  
- Extra KPIs  
- Additional filters  

### 5. Export the code

Use Lovable’s export option to download the generated project when available.

## Deliverables

- Working healthcare dashboard (link or export)  
- Exported source code (if the platform allows)  
- Screenshots of main views  

## Learning outcomes

- AI low-code / vibe-coding workflows  
- Rapid dashboard creation without starting from a blank repo  

## Tips

- Iterate in small prompts (e.g. “add a filter by department”) rather than one huge request.  
- Save URLs and exports early—some sessions may time out.
