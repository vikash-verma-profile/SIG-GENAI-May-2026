# Labs overview — AI for DataOps

Hands-on exercises live under **`lab-1`** … **`lab-10`**. Each folder has a **`README.md`** with objectives, file layout, prerequisites, step-by-step instructions, expected results, troubleshooting, and learning outcomes.

| Folder | Topic |
|--------|--------|
| [lab-1](./lab-1/README.md) | pytest suite for e-commerce ETL (`clean_sales_data`) |
| [lab-2](./lab-2/README.md) | GitHub Actions CI: flake8 + pytest + coverage |
| [lab-3](./lab-3/README.md) | Great Expectations: banking `transactions.csv` validation |
| [lab-4](./lab-4/README.md) | AI log analysis: telecom `app.log` → RCA / remediation |
| [lab-5](./lab-5/README.md) | Grafana + Docker: logistics dashboard workflow |
| [lab-6](./lab-6/README.md) | Azure Monitor / KQL + LLM incident summary |
| [lab-7](./lab-7/README.md) | RAG chatbot over ops logs (LangChain + Chroma + OpenAI) |
| [lab-8](./lab-8/README.md) | KPI dashboard design from `metadata.json` |
| [lab-9](./lab-9/README.md) | Azure Pipelines: Python, Docker, Kubernetes placeholder |
| [lab-10](./lab-10/README.md) | Anomaly detection on `metrics.csv` + LLM recommendations |

**Tip:** Open the `README.md` inside the lab you are running and follow commands from that lab’s directory unless noted otherwise.
