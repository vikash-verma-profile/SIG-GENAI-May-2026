# Lab 9 - Autonomous Data Quality Agent

## Objective
Create AI-powered data quality validation.

## Learning Outcomes

- Detect anomalies.
- Validate schema.
- Generate quality reports.

## Quality Checks

- Null values.
- Duplicate rows.
- Missing columns.
- Invalid data types.

## Detailed Steps

1. Install dependencies.

   ```bash
   pip install -r requirements.txt
   ```

2. Run the agent.

   ```bash
   python data_quality_agent.py
   ```

3. Review `quality_report.md`.

4. Modify `sales.csv` and rerun the lab.

## Exercises

- Add Great Expectations.
- Add automated alerts.
- Add anomaly detection.
- Export the report as JSON.
